# FloraScan AI

FloraScan AI is an intelligent plant pathology diagnostic tool designed for rapid detection of foliar crop diseases.
It combines lightweight edge machine learning with cloud-based multimodal AI fallback to provide real-time disease identification and actionable agricultural treatment guidance.

## What It Does
* **Plant Disease Detection:** Analyzes uploaded leaf imagery to detect crop pathogens, foliar spots, and plant stress.
* **Hybrid Condition Analysis:** Performs sub-second edge classification using TensorFlow Lite and automatically routes low-confidence predictions (<75%) to Google Gemini for visual verification.
* **Agronomic Suggestions & Advisory:** Delivers organic treatments, preventive cultural practices, chemical management protocols, and an interactive agronomic chatbot.

## Tools Used
* **Programming Language:** Python 3.11
* **Machine Learning & Edge Inference:** TensorFlow / TensorFlow Lite (TFLite)
* **Generative & Multimodal AI:** Google Gemini API
* **Web & API Framework:** FastAPI, Uvicorn, AnyIO
* **Deployment & Hosting:** Render Cloud Platform
